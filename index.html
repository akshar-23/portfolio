Some work that I've done

Northeastern University

Spacetime Level Generation

This research project, published at the AAAI 2025 AIIDE conference, explores a new frontier in procedural content generation. We modified the 'Sturgeon' constraint-solving system to generate 2D puzzle levels and their solutions at the same time, guaranteeing every puzzle is solvable by design. This co-generation method proved dramatically effective, running 100-500x faster and proving far more reliable than previous academic approaches like STWFC.

Otisco Studios

Red Circuit Rebellion

Red Circuit Rebellion is a high-speed mech shooter where players, as a rogue AI, unleash chaos in fully destructible industrial environments. The gameplay focuses on relentless pressure from adaptive enemy swarms and fast-paced arcade action. For this project, I developed over five core gameplay systems, including health and objective management, as well as the environmental fracturing mechanics. I also implemented the enemy AI for three distinct combat archetypes using Behavior Trees and EQS and built the logic for the game's Story and Arcade modes. A key contribution was optimizing game assets and blueprints, which successfully doubled the average FPS during gameplay.

Northeastern University

Smil-E-Mart

Created Smil-E-Mart, a narrative-driven simulation game where players uncover societal mysteries as a robotic cashier in a post-apocalyptic world. Designed core mechanics like item scanning, emoji-based dialogue, and branching storylines with 10+ decision points. Implemented systems to flag suspicious behaviors, influencing narrative outcomes. Achieved 90% player comprehension in playtests, with an average session length of 30 minutes, blending themes of morality, agency, and human connection.

Arcadon Games

Cricket Manager: League

Cricket Manager: League is a sports management simulation where players build their dream team, train star players, and use smart tactics to lead their club to victory. As a developer, I engineered the game's core mechanics, using state machines to improve gameplay responsiveness by 30%. I also built the complete backend architecture using Firebase, which supported over 1,000 concurrent users by managing user data, inventory systems, and real-time game progress synchronization. Additionally, I designed the AI simulation system capable of processing randomized matches, which enhanced gameplay variety and reduced load times.
